# Learn SecByte CTF Labs: Git, PwnKit, DeathNote & Meterpreter

A focused collection of Learn SecByte CTF and hands-on cybersecurity labs covering Git-related security scenarios, PwnKit/Polkit, DeathNote, SSH pivoting, GitShell/GitShadow, and Meterpreter.

These labs can be useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners building practical security skills in authorized lab environments.

## Introduction

This repository provides a searchable index of the Learn SecByte CTF and cybersecurity lab links supplied for this collection.

The topics represented by the URLs include:

- DeathNote lab setup and web-to-root basics
- Git shadow/GitShadow security scenarios
- GitShell escalation
- Git-based local exploit hunting
- PwnKit and Polkit breakout concepts
- Meterpreter
- Git login and SSH pivoting

Use the linked labs only in environments where you have permission to test.

## Learning Path

A practical way to explore the collection is:

1. Start with **DeathNote Lab Setup**.
2. Continue with **DeathNote Web to Root Basics**.
3. Explore the **Git Security** labs to understand Git-related attack surfaces.
4. Study the **PwnKit / Polkit** labs for Linux privilege escalation concepts.
5. Explore **GitShell** and **GitShadow** scenarios.
6. Finish with **Meterpreter Matrix** and the **SSH Pivot** lab for broader post-exploitation and pivoting concepts.

The exact difficulty of individual labs is not specified by the supplied URLs, so this repository does not assign difficulty ratings.

## How to Use the Labs

1. Open a lab from the direct index above.

3. Perform testing only against the authorized lab environment.
4. Record the security concepts and techniques you learn.
5. Use the experience to strengthen CTF, penetration testing, Linux security, and defensive analysis skills.
6. Avoid applying techniques to systems without explicit authorization.
